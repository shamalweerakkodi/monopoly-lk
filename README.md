# MONOPOLY-LK

MONOPOLY-LK is a Monopoly-inspired game simulation developed in C.

## Features

- 40-square game board
- Multiple player strategies
- Property purchasing and auctions
- Houses, hotels and renovations
- Rent, taxes and mortgages
- Bank loans and collateral
- Insurance and disasters
- Inflation and depreciation
- Economic events and government regulations
- National event cards
- Debt recovery and bankruptcy
- Net-worth calculation and winner selection
